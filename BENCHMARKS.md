## Isolation (mandatory)

The working tree must never show one run's implementation to another agent. **Before every run**: `./scripts/archive-results.sh` moves completed runs out of `results/` into `results-archive/` (kept tracked in git, so local and origin stay identical) — `new-run.sh` refuses to scaffold otherwise. Reading anything outside the active run directory is a hard fail (RUBRIC gate G6).
